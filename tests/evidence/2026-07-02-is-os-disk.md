# 2026-07-02 — storage.physical_disks[].is_os_disk 추가

## 무엇 / 왜

- **무엇**: 각 물리 디스크에 OS 루트 설치 여부를 나타내는 `is_os_disk` (Nice, `boolean|null`, OS 채널 전용) 추가.
- **왜**: 호출자가 physical_disks 목록에서 OS 가 설치된 디스크를 식별할 수단이 없었음 (physical_disks / logical_volumes 어디에도 부재).
- **결정**: 사용자 승인 (2026-07-02). 적용 범위 = OS 채널 한정 / baseline 값 = 토폴로지 기반 채움 + 실장비 확인은 NEXT_ACTIONS.

## 구현

| 채널 | 판정 로직 |
|---|---|
| OS Linux | `findmnt -n -o SOURCE /` (fallback `/proc/mounts`) → `lsblk -s -n -o NAME,TYPE <src>` 로 하위 물리 디스크 역추적(파티션/LVM/mdadm/multipath). `OSDISK|/dev/<name>` emit → 정규화 시 membership. python_ok + raw fallback 동일 구현. root 불필요. |
| OS Windows | `%SystemDrive%` → `Get-Partition.DiskNumber` (부재 시 WMI `Win32_DiskPartition.DiskIndex` fallback) → `Win32_DiskDrive.Index` 매칭. 물리 매칭 0건(가상디스크 등)이면 `null`. |

- `true`=OS 루트 디스크(RAID/LVM 멤버 모두 true), `false`=OS 루트 아님, `null`=판정 불가(SAN/iSCSI/NFS 루트 또는 도구 부재 — 거짓 false 안 냄).
- 기준은 OS 루트(`/`); `/boot`·EFI 별도 디스크는 false. Dell BOSS-N1 같은 부팅 NVMe 는 그 NVMe 가 true.
